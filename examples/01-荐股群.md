# 样例 1：小红书引流的荐股群

> 输入为根据监管通报常见套路改写的**虚构**话术，不指向任何真实个人或机构。

## 用户输入
> 小红书上看到一个博主天天晒涨停截图，私信后让我加微信进群。群里"王老师"说："进群先免费跟三只票试试水，觉得准再升级 VIP，VIP 群一年 9800，有机构调研的内部票，胜率 85% 以上。不赚钱全额退。今天名额只剩 5 个。"已经有好几个群友在晒收益。我心动了，要不要交？

## 输出

## 🚨 先说结论
高度符合监管通报的非法荐股特征，命中 7 面红旗。**先别交钱。**

## 场景
A 荐股 / 带单：公域引流 → 私域群 → 免费试用 → 付费 VIP。

## 逐句拆解
| 原话 | 类型 | 说明 |
|---|---|---|
| 天天晒涨停截图 | 说法 | 截图可挑选、可伪造，不能证明长期业绩 |
| 私信后让我加微信进群 | 话术技巧：引流私域 | 离开平台监管，便于后续操作 |
| 先免费跟三只票 | 话术技巧：低门槛试用 | 先建立信任，再推高价服务 |
| VIP 群一年 9800 | 说法 | 对方口头报价，未出示合同或收款主体；但已能说明这是有偿荐股 |
| 机构调研的内部票 | 说法 | 若属实涉嫌内幕信息，若不实即虚假宣传，两头都不对 |
| 胜率 85% 以上 | 说法 | 无可核验记录 |
| 不赚钱全额退 | 说法 | 通常没有书面合同保障 |
| 今天名额只剩 5 个 | 话术技巧：制造稀缺 | 逼你不经核验就决定 |
| 群友在晒收益 | 话术技巧：从众 | 监管通报中常见"托儿"晒单 |

## 对方可能怎么赚钱
（推断）主要收入是 VIP 会员费；也可能在你入群后推更贵的课程，或引导去其他品种 / APP。

## 命中的红旗
- 🚩 R-02 无资质有偿荐股 —— "VIP 群一年 9800" —— 收费荐个股需证监会许可 —— 四川证监局
- 🚩 R-04 公域引流到私域 —— "私信后让我加微信进群" —— 深圳 / 江苏证监局
- 🚩 R-07 内幕消息 —— "机构调研的内部票" —— 深圳证监局
- 🚩 R-15 制造紧迫感 —— "名额只剩 5 个" —— 金融监管总局
- 🚩 R-16 群托晒单 / 免费后升级 —— "先免费跟三只票""群友晒收益" —— 证监会
- 🚩 R-03 不赚钱不收费类承诺 —— "不赚钱全额退" —— 贵州证监局
- 🚩 R-01 变相承诺收益 —— "胜率 85% 以上" —— 金融监管总局
- 🔎 查漏：A 类还有 R-05（非官方 APP）、R-06（跨品种转移）、R-10（转到个人账户）没出现——如果王老师接下来让你下载"内部交易软件"、改做外汇黄金，或把钱转给个人，立刻停。

## 对方没告诉你的
- 王老师的真实姓名、执业机构和证券投资咨询执业编号
- 收款方是谁（公司对公账户还是个人）
- 退款条件的书面约定
- 过去推荐的完整记录（包括亏损的票）

## 可以直接发给对方的问题
1. 请发一下您在中国证券业协会公示的执业编号和所属机构，我自己去官网查。
2. 9800 元付给哪个公司？请发对公账户和服务合同。
3. "全额退"写在合同哪一条？
4. 能否提供过去 12 个月全部推荐记录，包括亏损的？
