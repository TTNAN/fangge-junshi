# 对方怎么赚钱 (Incentive Map)

> 这是行业常见收入模式，用于帮助用户理解"对方为什么这么说"。使用时必须注明"推断"，不得据此指控具体个人。不写具体佣金比例，除非用户提供了合同或费率表原文。

| 场景 | 常见收入来源 | 由此产生的倾向 |
|---|---|---|
| 持牌银行 / 券商销售 | 销售佣金、尾随佣金、业绩考核 | 倾向推销费率更高、考核权重更高的产品 |
| 保险代理人 | 首年佣金通常显著高于续年 | 倾向推长期缴费、储蓄型产品，强调"收益"而淡化退保损失 |
| 无资质"老师"/群主 | 入群费、课程费、会员费、打赏、盈利分成 | 倾向晒战绩、制造稀缺、推升级套餐 |
| 庄家配合的"黑嘴" | 让你接盘，他们反向卖出 | 倾向"限时、现价、全仓跟买" |
| 虚拟盘 / 对赌平台 | 你的本金和亏损 = 他们的收入 | 倾向鼓励加仓、高杠杆、频繁交易，阻止提现 |
| 非法集资项目 | 用新钱付旧钱 | 初期按时兑付，鼓励拉人头和复投 |
| 贷款中介 / "征信修复" | 前期服务费、砍头息、导流费 | 倾向收"前期费用"，承诺"包下款" |

出处参见 `red-flags.md` 中 R-03、R-06、R-10、R-14 等条目所引官方文件。
