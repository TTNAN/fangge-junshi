## R-01 承诺保本保收益
- **特征**：宣称"保本""稳赚不赔""保证年化 X%""零风险"。
- **依据**：资管新规起金融机构资产管理业务不得承诺保本保收益；"保本高息""专家保证"是虚假网络投资理财诈骗的常见套路。理财产品销售不得直接或变相宣传、承诺保本保收益。
- **出处**：国家金融监督管理总局风险提示（新华网转载，2023-09-19）http://www.news.cn/fortune/2023-09/19/c_1129870786.htm ；《理财公司理财产品销售管理暂行办法》第四条 https://www.gov.cn/gongbao/content/2021/content_5625997.htm
- **最后核验**：2026-10-13

## R-02 无资质有偿荐股
- **特征**：未持证的个人或机构收费提供个股分析、预测或建议（入群费、会员费、打赏、盈利分成）。
- **依据**：未取得证监会核发的证券投资咨询业务许可，任何机构和个人有偿提供个股分析、预测或建议，均是非法荐股。
- **出处**：四川证监局《非法荐股骗局大揭秘》https://www.csrc.gov.cn/sichuan/c106369/c7561746/content.shtml
- **最后核验**：2026-10-13

## R-03 盈利分成 / 先荐股后抽成
- **特征**："先荐股、赚了五五分""不赚钱不收费"。
- **依据**：贵州证监局列为新型非法荐股骗局，常伴随"专用账户"虚拟盘、大额提现被拒。
- **出处**：https://www.csrc.gov.cn/guizhou/c105473/c7621548/content.shtml
- **最后核验**：2026-10-13

## R-04 公域引流到私域
- **特征**：从抖音、小红书、雪球、直播间引导加微信 / QQ / 钉钉 / 小众 APP 群聊。
- **依据**：引流至"私域"作案已成为惯用手法。
- **出处**：深圳证监局风险提示 http://www.csrc.gov.cn/shenzhen/c105615/c7562405/content.shtml ；江苏证监局 https://www.csrc.gov.cn/jiangsu/c105410/c7612290/content.shtml
- **最后核验**：2026-10-13

## R-05 要求下载非官方 APP / 私发链接 / "VIP 内部 APP"
- **特征**：通过私人链接下载交易软件，声称是"VIP 客户专属内部 APP"。
- **依据**：入金后无法提现，随后被删除拉黑。
- **出处**：深圳证监局《关于警惕非法荐股骗局的风险提示》（2026-06-11）https://www.csrc.gov.cn/shenzhen/c105615/c7638512/content.shtml
- **最后核验**：2026-10-13

## R-06 跨品种转移（股票 → 期货/外汇/虚拟币/现货）
- **特征**：荐股不灵后，劝你转去"收益更高、风险更低"的外汇、贵金属、虚拟币、现货。
- **依据**：常为杠杆交易或后台操控的虚拟盘，平台与投资者对赌。
- **出处**：证监会《股市投资者需谨防被诱导参与非法投资交易》http://www.csrc.gov.cn/csrc/c106299/c1600727/content.shtml ；贵州证监局（2026-03-24）
- **最后核验**：2026-10-13

## R-07 内幕消息 / 庄家 / 高中签率 / 原始股
- **特征**："内幕消息""机构调研票""游资已到位""高中签率""即将上市的原始股"。
- **依据**：证监会提示的诈骗常见宣传用语。
- **出处**：深圳证监局（2026-06-11）；证监会湖南局《破解证券诈骗"四个"妙招》http://www.csrc.gov.cn/hunan/c105684/c1293772/content.shtml
- **最后核验**：2026-10-13

## R-08 AI / 量化 / 大数据炒股神器
- **特征**：付费购买"AI 选股""量化交易软件""自动买卖"。
- **依据**：利用热门概念包装粗制滥造软件实施荐股或诈骗。
- **出处**：四川证监局 https://www.csrc.gov.cn/sichuan/c106369/c7561747/content.shtml ；江苏证监局（2026-01-30）
- **最后核验**：2026-10-13

## R-09 冒充持牌机构人员
- **特征**：出示"工作证"、盗用从业人员公示信息、平台认证为"理财师"。
- **依据**：深圳证监局列为主要套路之一。
- **出处**：https://www.csrc.gov.cn/shenzhen/c105615/c7638512/content.shtml
- **最后核验**：2026-10-13

## R-10 转账到个人账户 / 无关第三方 / 交钱"解冻"
- **特征**：要求转到个人或不相关公司账户；提现时要求先交保证金、税费、"解冻费"。
- **依据**：均可能涉嫌诈骗。
- **出处**：深圳证监局（证券时报转载）https://www.stcn.com/article/detail/3957291.html
- **最后核验**：2026-10-13

## R-11 场外配资 / 高杠杆炒股
- **特征**："1 比 10 放大资金""借钱给你炒股"。
- **依据**：场外配资属违法。
- **出处**：贵州证监局（2026-03-24）
- **最后核验**：2026-10-13

## R-12 把保险说成存款、理财或基金
- **特征**：以银行理财、存款、基金的名义卖保险；用分红率、结算利率与存款利率简单对比。
- **依据**：属于保险销售误导的典型表现。
- **出处**：金融监管总局《关于防范保险销售误导的风险提示》https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1071714&generaltype=0&itemId=4100
- **最后核验**：2026-10-13

## R-13 夸大收益或保障范围 / 混淆产品
- **特征**：混淆存款、理财、基金、信托、保险；夸大收益或保障范围；推介超出你风险承受能力的产品。
- **依据**：《金融机构产品适当性管理办法》（2026-02-01 起施行）第十三条禁止行为。
- **出处**：https://www.gov.cn/gongbao/2025/issue_12246/202508/content_7038009.html
- **最后核验**：2026-10-13

## R-14 非法集资三要件
- **特征**：未经许可 + 许诺还本付息或其他回报 + 面向不特定公众（朋友圈、群、讲座、广告）。常见名义：股权、私募、养老、消费返利、虚拟货币、融资租赁。
- **依据**：《防范和处置非法集资条例》第二条、第十九条。
- **出处**：https://www.gov.cn/zhengce/content/2021-02/10/content_5586632.htm
- **最后核验**：2026-10-13

## R-15 制造紧迫感 / 限时 / 名额有限
- **特征**："今天最后一天""名额只剩 3 个""错过再等一年"。
- **依据**：金融监管总局提示警惕"免费""零首付""限时"等营销词汇。
- **出处**：金融监管总局风险提示（中银保险转载）https://www.boc.cn/bocins/cusser/cs5/202409/t20240913_25154084.html
- **最后核验**：2026-10-13

## R-16 群托晒单 / 免费试用后升级 VIP
- **特征**：群内"学员"晒盈利截图，先免费荐几只票，再推销上万元课程或 VIP。
- **依据**：证监会、深圳证监局多次提示。
- **出处**：证监会《警惕互联网"非法荐股"风险》http://www.csrc.gov.cn/csrc/c106299/c1600723/content.shtml
- **最后核验**：2026-10-13

## R-17 收费"征信修复" / "洗白征信"
- **特征**：声称花钱就能删除逾期记录、"消除不良征信"、"内部渠道修复"。
- **依据**：征信机构和金融机构都无权随意更改删除正确的信用信息，凡是声称合法的、收费的"征信修复"都是骗局；只有对错误信息的异议更正机制。
- **出处**：金融监管总局河北监管局 https://www.nfra.gov.cn/branch/hebei/view/pages/common/ItemDetail.html?docId=1128636&generaltype=0&itemId=1820
- **最后核验**：2026-10-13

## R-18 "包下款" / 先交钱后放款
- **特征**："无抵押无担保""黑户也能贷""包过""内部通道"；放款前先收"包装费""担保费""沟通费""解冻费"。
- **依据**：非法中介以低息引诱，再以资质不足需"包装运作"或担保费、沟通费等名义索要高额费用。
- **出处**：北京金融监管局（中银保险转载）https://www.bankofchina.com/bocins/cusser/cs5/202510/t20251031_25549788.html ；原银保监会 2022 年第 7 期风险提示（中银保险转载）https://www.bankofchina.com/bocins/cusser/cs5/202212/t20221230_22341052.html
- **最后核验**：2026-10-13

## R-19 "债务重组" / 高息垫资过桥 / 砍头息
- **特征**："债务优化""帮你借新还旧""先垫资帮你养征信"，放款时按比例扣服务费。
- **依据**：不法贷款中介诱导借新还旧、申请高息过桥垫资，收取垫资费和按放款额比例的高额服务费。
- **出处**：金融监管总局消保局（中银保险转载）https://www.boc.cn/bocins/cusser/cs5/202503/t20250311_25290230.html
- **最后核验**：2026-10-13

## R-20 只报日息月息 / 把贷款说成"分期付款"
- **特征**："日息万三""月费率 0.5%"，不报年化利率和综合成本；用"分期缴费""分期付款"代替"分期贷款"。
- **依据**：金融监管总局列为虚假宣传诱导网络贷款的套路：混淆概念、不实承诺、隐瞒实际年化利率和综合借贷成本。
- **出处**：金融监管总局《关于防范虚假宣传诱导网络贷款的风险提示》（2025-07-10）https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1217677&itemId=4100 ；备用：新华网报道 https://www.xinhuanet.com/20250711/f3b5c4e36a814d28961694e737be0f3a/c.html 。链接打不开时，在金融监管总局官网"消费者教育及风险提示"栏目搜索标题。
- **最后核验**：2026-10-13

## R-21 冒充公检法 / "安全账户" / 屏幕共享
- **特征**：自称公安、检察院、法院，说你涉嫌洗钱等犯罪；发"通缉令""逮捕令"；要求保密、下载会议软件开屏幕共享、把钱转入"安全账户""监管账户"做"资金核查"。
- **依据**：公检法机关没有"安全账户"；不会通过电话、社交软件办案或发送法律文书；凡要求转账核查、下载陌生软件、开屏幕共享的都是诈骗。
- **出处**：司法部智慧普法平台《公安机关发布20个防诈关键词》https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202506/t20250620_521303.html ；深圳市公安局 https://ga.sz.gov.cn/JMHD/YWZSK/XJGL_ZS/content/post_10553452.html ；北京市公安局（2026-01-13 发布会，西藏网信办转载）https://wxb.xzdw.gov.cn/wlaq/yjtb/202601/t20260114_641331.html
- **最后核验**：2026-10-13

## R-22 假追损 / 代理维权 / "帮你追回被骗的钱"
- **特征**：被骗后有人主动联系，声称是律师、"维权机构"、"P2P 清退专员"，"不成功不收费"，先收手续费或要你提供银行卡、验证码。
- **依据**：受骗后应报案并通过刑事追赃、民事诉讼追偿，绝不轻信"维权机构"，严防二次受骗；金融监管总局提示"代理维权"乱象以"不成功不收费"为噱头收取高比例提成、手续费。
- **出处**：贵州证监局（2026-03-24）https://www.csrc.gov.cn/guizhou/c105473/c7621548/content.shtml ；金融监管总局《关于警惕涉金融领域"代理维权"风险的提示》（中国政府网）https://www.gov.cn/lianbo/bumen/202405/content_6950654.htm
- **最后核验**：2026-10-13

## R-23 RWA / 现实世界资产代币化 / 虚拟货币炒作
- **特征**："RWA 稳赚""现实世界资产上链""境外合规发行"；虚拟货币理财、"挖矿"、稳定币高息；宣称境外牌照、国家背书。
- **依据**：八部门明确在境内开展现实世界资产代币化活动应予以禁止（涉嫌非法发售代币票券、擅自公开发行证券、非法经营证券期货业务、非法集资）；一些不法分子打着虚拟货币、RWA、"挖矿"等幌子开展非法集资、传销诈骗。
- **出处**：中国人民银行等八部门《关于进一步防范和处置虚拟货币等相关风险的通知》（银发〔2026〕42号，2026-02-06）https://www.pbc.gov.cn/tiaofasi/144941/3581332/2026020619591971323/index.html
- **最后核验**：2026-10-13

## R-24 数字藏品 / NFT 炒作
- **特征**："数字藏品"承诺升值、炒作转卖；平台搞集中竞价、做市商、标准化合约；用虚拟货币计价结算；以"元宇宙""Web3"概念包装。
- **依据**：三协会倡议坚决遏制 NFT 金融化证券化倾向：不在 NFT 底层商品中包含证券、保险等金融资产；不得通过分割所有权等方式变相开展代币发行融资；不得提供集中交易；不得用虚拟货币计价结算。
- **出处**：中国互联网金融协会、中国银行业协会、中国证券业协会《关于防范NFT相关金融风险的倡议》（2022-04-13）。政府官网转载全文（已亲手打开验证标题与正文一致）：https://www.xiuzhou.gov.cn/art/2022/9/15/art_1228969058_59205758.html 。三协会自有官网（nifa.org.cn 等）从本机网络无法打开，故引用政府转载页。
- **最后核验**：2026-10-13
