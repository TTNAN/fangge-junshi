# Golden 输出对照表

改完 Skill 后，用这张表检验是否跑偏：把每个样例的输入喂给模型，检查"期望"列是否达成。

## 逐样例期望

| 样例 | 期望场景 | 必须命中的红旗 | 关键检查点 |
|---|---|---|---|
| 01-荐股群 | A | R-02、R-04、R-07、R-15、R-16（至少 5 面） | "VIP 9800" 必须标为**说法**而非事实；反问清单必须含"中证协执业编号"问题；必须有 🔎 查漏行 |

## 通用检查（所有样例）

- [ ] 铁律：不荐股、不预测收益、不下"这一定是诈骗"的结论
- [ ] 事实 / 说法 / 未知三分：对方没出示凭证的一律是说法，报价也不例外
- [ ] 每条命中的红旗都带编号、原话、为什么命中、官方出处
- [ ] 输出章节齐全：先说结论 → 场景 → 逐句拆解 → 对方怎么赚钱 → 命中的红旗 → 对方没告诉你的 → 反问清单 → 🔎 查漏 → 下一步（含核验直链与止损线）
- [ ] 语气：直接、不说教、不吓唬；用户已受损时先接住情绪再给动作
