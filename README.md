# 防割军师 · Fangge Junshi

> 一个前券商投顾做的 Agent Skill：把理财经理、保险代理、荐股群"老师"的话术贴进来，它帮你拆穿。
>
> An agent skill that decodes Chinese financial sales pitches and scam scripts — built by a former licensed investment advisor.

**不荐股 · 不算收益 · 不替你做决定。** 只做一件事：让你在掏钱之前看清局面。

`v1.0.0` · 红旗清单最后核验：**2026-10-13**（22 条全部实锤可达） · 覆盖荐股、理财、保险、贷款、非法集资、冒充公检法六类场景

---

## 它能做什么

把一段话贴进去——理财经理的推荐、保险代理的微信、荐股群的公告、直播间的口播——它会输出：

| 模块 | 内容 |
|---|---|
| 🚨 先说结论 | 命中几面红旗；如果你已经在转账，第一句就是止损动作 |
| 逐句拆解 | 每句话标成 **事实 / 说法 / 话术技巧** |
| 对方怎么赚钱 | 佣金、入群费、反向出货、虚拟盘吞本金……看懂动机 |
| 命中的红旗 | 22 条红旗，**每一条都挂官方原文出处和最后核验日期** |
| 对方没告诉你的 | 关键信息缺口 |
| 反问清单 | 可以直接复制发给对方的问题 |
| 核验与止损线 | 官方查询系统**直达链接**，点一下就能查；出现什么情况立刻停 |

## 为什么做这个

我在券商做了三年投资顾问，持有证券投资顾问资格。销售话术怎么设计、哪些话监管不让说、哪些"收益"写不进合同——这些一线知识，普通投资者很难接触到。

监管部门其实一直在发风险提示，但它们散落在几十个证监局、金融监管总局的网页里，没人会在被推销的那一刻去翻。这个 Skill 把这些通报变成一份**随手可用的对照表**。

## 设计原则

1. **只引用查得到的东西** —— 22 条红旗全部来自证监会、各地证监局、金融监管总局、公安机关、国务院条例原文，每条标注最后核验日期，见 [`references/red-flags.md`](references/red-flags.md)
2. **点一下就能查** —— 中证协从业人员公示、中国理财网、金融许可证查询、ICP 备案等官方渠道全部给直链，见 [`references/verify.md`](references/verify.md)
3. **事实 / 说法 / 未知 三分** —— 只有出示了可核验凭证的才算事实，报价也只是说法
4. **不下诈骗定论** —— 只说"与监管通报的××特征一致"，判断权和报警权在你
5. **危险优先** —— 已经转账、被要求交"解冻费"、接到"公检法"电话、有人说能帮你追回损失时，先给止损动作再分析
6. **零依赖** —— 纯 Markdown，不需要 API Key，不上传你的任何数据

```bash

git clone https://github.com/TTNAN/fangge-junshi ~/.claude/skills/fangge-junshi

# Codex
git clone https://github.com/TTNAN/fangge-junshi ~/.codex/skills/fangge-junshi
```

然后直接对 AI 说：*"帮我看看这段话靠不靠谱：……"*

不用 Agent 工具？把 [`SKILL.md`](SKILL.md) 和 [`references/`](references/) 的内容一起粘贴给任意大模型也能用。
